    1. When creating singleton methods (i.e. def self.foo), Ruby creates an anonymous class to hold them. This anonymous class — the eigenclass — assumes the role of the object’s class, and the original class is re-designated as its superclass.
    2. private is actually a method.
    3. The private method only changes the visibility of instance methods.
    4. Class methods, on the other hand, are instance methods of the eigenclass.

    Here’s how a function call with an ampersand looks:

    some_function(&an_object)

    When used like this, the & operator calls to_proc on the argument and passes the resulting Proc object (explained below) as a block to the method.

    What’s a Proc?
